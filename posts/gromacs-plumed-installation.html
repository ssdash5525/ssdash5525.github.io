This is a consolidated installation guide for building GROMACS 2024.5 patched with PLUMED 2.9.3 on the KALAM cluster, including a fix for the MPI rank error that arises when the system defaults to MPICH instead of OpenMPI.

1. Extract the source archives

Download plumed-2.9.3.tgz and gromacs-2024.5.tar.gz, then extract both:

tar -xvzf plumed-2.9.3.tgz
tar -xvzf gromacs-2024.5.tar.gz

2. Install PLUMED

# Enter the PLUMED source directory
cd /path/to/plumed-2.9.3

./configure \
  --prefix="/home/mb/softies/plumed293" \
  --enable-mpi \
  --disable-almost \
  --enable-matheval \
  CXX=mpiCC

make -j 32 && make install
Note: --enable-matheval requires libmatheval to be available on the system. If the configure step fails on this flag, see reference [3] below for a workaround.

3. Install GROMACS with PLUMED patch

3a — Patch GROMACS

Source the PLUMED environment and apply the patch before running CMake. If GROMACS 2024.5 is not listed as a supported version, choose the nearest available version when prompted.

export PLUMED_ROOT="/home/mb/softies/src/plumed-2.9.3"
source $PLUMED_ROOT/sourceme.sh

cd /path/to/gromacs-2024.5
$PLUMED_ROOT/src/lib/plumed patch -p
# Select the nearest GROMACS version if 2024.5 is not listed

3b — Configure and build

mkdir build && cd build

cmake .. \
  -DGMX_BUILD_OWN_FFTW=ON \
  -DGMX_GPU=CUDA \
  -DCMAKE_INSTALL_PREFIX=/home/mb/softies/gro2024_cuda_plumed_mpi \
  -DGMX_THREAD_MPI=OFF \
  -DGMX_MPI=ON \
  -DCMAKE_C_COMPILER=/usr/bin/gcc-12 \
  -DCMAKE_CXX_COMPILER=/usr/bin/g++-12

make -j 32 && make install

4. Verify MPI and OpenMP linkage

Check that both binaries are linked against OpenMP and MPI libraries. You are looking for libgomp.so.1 (OpenMP) and libmpich.so.12 or libmpi.so (MPI) in the output. 

ldd ~/softies/plumed293/bin/plumed
ldd ~/softies/gro2024_cuda_plumed_mpi/bin/gmx_mpi

5. Fixing the MPI rank error on KALAM

KALAM may default to MPICH for mpirun and mpiexec. MPICH requires more than one physical node to launch, so single-node jobs fail. The fix is to switch the system default to OpenMPI.

5a — Diagnose

Check which MPI implementation is currently active:

update-alternatives --get-selections | grep mpi

If the output shows mpich entries like the following, you need to switch:

# Bad — linked to MPICH
mpi                   auto   /usr/bin/mpicc.mpich
mpirun                auto   /usr/bin/mpirun.mpich
mpi-x86_64-linux-gnu  auto   /usr/include/x86_64-linux-gnu/mpich

5b — Reinstall OpenMPI

sudo apt-get install --reinstall openmpi-bin

5c — Confirm the switch

update-alternatives --get-selections | grep mpi

The output should now point to openmpi:

# Good — linked to OpenMPI
mpi                   auto   /usr/bin/mpicc.openmpi
mpirun                auto   /usr/bin/mpirun.openmpi
mpi-x86_64-linux-gnu  auto   /usr/include/x86_64-linux-gnu/mpich
Note: The header path (mpi-x86_64-linux-gnu) may still show the MPICH include path even after switching — this is normal and does not affect runtime behaviour.

6. Running GROMACS with PLUMED

Once OpenMPI is the active default, launch an MD run with PLUMED as follows:

mpiexec -np 2 --oversubscribe gmx_mpi mdrun -plumed plumed.dat
Tip: Adjust -np 2 to the number of MPI ranks appropriate for your job. The --oversubscribe flag allows ranks to exceed physical cores — useful for testing but not recommended for production runs.
